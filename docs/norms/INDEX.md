# Нормативная база РК — реестр документов

Единственный источник нормативных требований проекта. PDF лежат рядом в этой
папке И ХРАНЯТСЯ В GIT — решением владельца от 06.08.2026, подтверждённым
повторно 08.08.2026. Условие решения: репозиторий приватный; официальные
издания под авторским правом и распространению не подлежат. При открытии
репозитория правило пересматривается первым. Текстовые выгрузки с маркерами
страниц — в `txt/` (вне git).

Одиннадцать документов положены 09.08.2026. Каждый сверен по титульному листу и
числу страниц с записью этой таблицы: совпадают и документ, и издание.

Правила применения:
- Иерархия: Кодексы РК > СН РК > СП РК > ГОСТ. Российский ГОСТ Р — только методический образец.
- При расхождении изданий действует более позднее, если пользователь не решил иначе. Конфликты — в [CONFLICTS.md](CONFLICTS.md).
- Двуязычные документы: используются русские страницы.
- Страницы везде указываются как страницы PDF файла (не типографские).

## Чего в наборе НЕТ (запрошено у пользователя)

1. **Строительные нормы по водоснабжению** (аналог СН РК 4.01-03, но для
   водопровода: СН РК 4.01-02 / СП РК 4.01-101). Модуль В1 — главный в
   продукте; все его записи реестра остаются `unverified`, пока документ не
   будет передан.
2. **СП РК 2.03-30** (строительство в сейсмических зонах) — сейсмика площадки
   сейчас без официального источника.
3. **Климатические данные** (СП РК 2.04-01 или аналог) — глубина промерзания,
   дождевые параметры q20 по регионам.
4. **Правило именования слоёв САПР.** Запись `drawing.layers` ссылается на
   ГОСТ 21.704-2011, но полнотекстовый поиск по обоим имеющимся ГОСТ
   (21.704-2011 и Р 21.101-2020) такого требования не находит: в 21.101
   встречается только «многослойные конструкции», это о другом. Пока источник
   не назван, запись остаётся `unverified`.
5. **ТЗ на проектирование**, на которое ссылаются пять записей реестра
   (п. 6.1). В имеющемся АПЗ нет ни пункта 6.1, ни красных линий, ни футляров,
   ни защитных решёток — это другой документ.
