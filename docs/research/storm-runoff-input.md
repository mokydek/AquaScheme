# Входные данные расчёта дождевого стока К2

Расчёт 5.8–5.13 подключён к `datasets.kind = drainage`. Нормативный расход имеет приоритет над ручным `design_flow_lps`; ручное значение позволяет проверить черновую гидравлику, но не разрешает финальный выпуск.

Минимальная структура `content`:

```json
{
  "stormCatchments": [
    {
      "id": "C-01",
      "inflowId": "идентификатор точки притока",
      "rain": {
        "q20LpsPerHa": 0,
        "exponentN": 0,
        "rainEventsPerYearMr": 0,
        "exponentGamma": 0,
        "designPeriodYears": 0,
        "source": "идентификатор климатического источника",
        "verified": false
      },
      "surfaces": [
        {
          "id": "surface-01",
          "kind": "impervious",
          "areaHa": 0,
          "source": "идентификатор топографического/планировочного источника",
          "verified": false
        }
      ],
      "surfaceConcentrationMin": 0,
      "gutterSegments": [],
      "pipeSegments": [],
      "meanTerrainSlope": 0,
      "networkSectionCount": 0
    }
  ]
}
```

Нули в примере намеренно не являются значениями по умолчанию: валидатор их отклонит. Требуются фактические положительные числа и подтверждённые источники.

Поддерживаемые поверхности: `impervious`, `paved_block`, `cobblestone`, `unbound_crushed_stone`, `gravel_path`, `graded_soil`, `lawn`. Для водонепроницаемых покрытий коэффициент берётся из таблицы 5.11 по `A` и `n`; для остальных — из таблицы 5.10. Явный `coefficientZ` допустим только как подтверждённое значение входной карточки. За пределами табличного диапазона `A=300…1500` молчаливое прижатие или экстраполяция запрещены: нужен подтверждённый override с источником. То же правило действует для коэффициента площади `K` за пределами таблицы 5.9.

Стоп‑факторы формируются, если:

- не подтверждены `q20`, `n`, `m_r`, `gamma`, `P` или покрытия;
- время меньше 10 минут и не попадает в прямо заданные случаи 5/7 минут, а подтверждённой поправки нет;
- уклон 0,01–0,03, но инженер не выбрал допустимое увеличение `beta` 10–15%;
- внешний незастроенный водосбор больше 1000 га требует иного метода;
- отсутствует водосбор для какой-либо точки притока.
- `A` или площадь выходят за диапазон применяемой таблицы, а подтверждённый override отсутствует.

Для площади свыше 50 га программа выдаёт обязательное предупреждение о проверочных расчётах частей водосбора. Для площади 500–10000 га применяется коэффициент таблицы 5.9. Любая линейная интерполяция фиксируется одновременно в `warnings` и структурированном `provenance` с обеими границами таблицы. Все формулы и таблицы связаны с ID `storm.runoff.*` в реестре норм.
