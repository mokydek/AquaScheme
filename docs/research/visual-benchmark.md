# Постраничный visual benchmark

`npm run benchmark:visual` — строгий локальный приёмочный тест. Он не передаёт эталон генератору и не сохраняет конфиденциальные страницы в Git. Оба PDF читаются только после завершения расчёта и экспорта.

Локальный файл `docs/benchmark/manifest.json` должен дополнительно к реестру исходников содержать:

```json
{
  "referencePdf": "R01.pdf",
  "generatedPdf": "out/generated-album.pdf",
  "expectedPages": 61,
  "visualThreshold": 0.99,
  "renderWidthPx": 1000,
  "renderHeightPx": 707,
  "visualReport": "out/reports/page-comparison.json",
  "visualHtmlReport": "page-comparison.html",
  "visualMarkdownReport": "final-validation.md",
  "visualArtifacts": "out/artifacts"
}
```

Пути разрешаются относительно манифеста и остаются внутри gitignored benchmark‑среды владельца данных. Проверка сохраняет JSON, HTML, Markdown и три набора PNG: `reference-pages`, `generated-pages`, `diff-pages`. Красные области diff показывают фактические отличия; эти артефакты не добавляются в Git.

## Метрики

- `pixelSimilarity` — среднее поканальное RGB-совпадение. Оно чувствительно к общему виду и различает цвета с близкой яркостью, но само по себе может быть завышено белыми полями.
- `inkIoU` — пересечение чёртежной графики и текста; белые поля не скрывают смещённые линии.
- `structureSimilarity` — совпадение плотности графики по сетке ячеек, то есть крупной компоновки листа.
- `combined` — строгая итоговая оценка: 20% pixel, 40% ink IoU, 40% structure.

Для прохождения каждый лист и среднее значение должны быть не ниже `visualThreshold`. Несовпадение числа страниц всегда завершает проверку ошибкой. Порог 99% является критерием валидации конкретного контрольного проекта, а не обещанием для произвольных входных данных.

Самотест рендера на одинаковом PDF с явным `--self-test` дал 100% для каждой страницы; обычный acceptance-режим отвергает одинаковые файлы, число страниц не равное 61, порог ниже 99%, слишком малый растр и несовпадение MediaBox. Unit‑тесты отдельно доказывают, что смещение графики не маскируется большим белым фоном и что близкие по яркости, но разные RGB-цвета не считаются одинаковыми.
