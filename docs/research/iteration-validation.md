## Визуальный benchmark

Инструмент `scripts/visual-benchmark.mjs --self-test` проверен на одном девятистраничном PDF: все страницы получили 100%. Этот результат доказывает только воспроизводимость рендера и формата отчёта. Обычный acceptance-режим отклоняет одинаковые файлы, число страниц не равное 61, порог ниже 99% и слишком малый растр; MediaBox сравнивается отдельно. Самотест **не является** оценкой сходства AquaScheme с реальным 61-страничным эталоном.

Для реальной приёмки нужны одновременно:

1. сгенерированный приложением полный альбом без `BLOCKED`/`PRELIMINARY` листов;
2. локальный приватный manifest с путями к эталону и результату;
3. подтверждённые источники, перечисленные в `missing-data-report.md`;
4. прогон страницы-к-странице с JSON, HTML, Markdown и PNG-различиями.

Пока этих условий нет, `npm run benchmark` честно завершается без оценки, а значение 99% не заявляется.
