# AquaScheme

Автоматизированный проектировщик наружных сетей водоснабжения, бытовой и ливневой канализации.

Сценарий: инженер загружает исходные данные (топосъёмка, готовая трасса DWG/DXF/GeoJSON, расходы, геология и сейсмика). Для напорного водоснабжения система использует EPANET 2.2; для самотечной бытовой и ливневой сети — расчёт частично заполненной круглой трубы по Шези–Маннингу. Результат включает подбор диаметров и сооружений, планы и продольные профили DXF/DWG, пояснительную записку PDF, ведомости и спецификации XLSX.

Для реального объекта водосбросного коллектора требуется настроенный сервис `converter/`: приложенная топооснова имеет формат DWG и без преобразования в DXF не может быть прочитана браузером.

После конвертации полный DWG разбирается по назначению слоёв: инженерный коридор, красные линии, существующие коммуникации, дороги, гидрография, рельеф и высотные точки не смешиваются с готовой осью сети. Кнопка «Построить трассу по генплану и ограничениям» прокладывает связное дерево внутри замкнутого коридора, штрафует пересечения и показывает их в отчёте. Если коридор или система координат отсутствуют, срабатывает стоп-фактор — произвольные прямые соединения не создаются. Итоговый альбом реального проекта используется только в автоматическом тесте сравнения и не является входом алгоритма или вставленным изображением.

## Структура репозитория

| Папка | Назначение |
| --- | --- |
| `frontend/` | Веб-приложение: React + TypeScript (Vite). Включает лендинг (маршрут `/`) и рабочую область (`/app`) |
| `engine/` | Расчётное ядро: чистый TypeScript без React. Водопотребление, трассировка, гидравлика, подбор диаметров, генераторы DXF/PDF. Покрывается unit-тестами |
| `backend/` | Supabase: миграции схемы БД, политики RLS, edge functions |
| `docs/` | Документация проекта, статус фаз разработки |

## Команды

Все команды выполняются из корня репозитория (npm workspaces):

```bash
npm install        # установка зависимостей всех пакетов
npm run dev        # dev-сервер фронтенда (http://localhost:5173)
npm run build      # production-сборка фронтенда
npm run test       # unit-тесты расчётного ядра
npm run typecheck  # проверка типов во всех пакетах
npm run benchmark  # локальная сверка с конфиденциальным эталонным альбомом, если исходники доступны
```

## Технологический стек

React 19, TypeScript, Vite 7, React Router 7, MapLibre GL JS, turf.js, epanet-js (WASM), @tarikjabiri/dxf, pdfmake, Supabase, Vercel.

## Нормативная база

СН РК 4.01-03-2013*, СП РК 4.01-103-2013, СН РК 1.02-03-2022, ГОСТ 21.704-2011, ГОСТ 21.110-2013; для водоснабжения — СП РК 4.01-101-2012. Точные пункты и статус проверки ведутся в `docs/norms/`.

## Дисклеймер

Система является инструментом автоматизации проектирования. Окончательные решения принимает инженер; проект подлежит экспертизе в установленном порядке.
